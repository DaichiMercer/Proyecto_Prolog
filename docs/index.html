¿Cómo funciona?

La interfaz entrega valores a tus predicados Prolog.

  1. Seleccionas plataforma, presupuesto y tus preferencias.
  2. La página crea una consulta para recomendar/10, alternativa/10 o motivo_descarte/7.
  3. Tau Prolog evalúa los hechos y las reglas del archivo de conocimiento.
Importante: el precio y las categorías provienen de la base de conocimiento del proyecto. Son valores de referencia, no datos de tiendas en tiempo real.
